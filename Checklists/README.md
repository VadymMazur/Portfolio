# Checklist templates

These are learning examples, not completed test runs. Earlier illustrative Pass/Fail values have been replaced with **Not run**. No IDOR discovery, outage, Jira ticket or production result is asserted by these templates.

| Checklist | Focus |
|---|---|
| [Functional](Functional_Checklist.md) | Navigation, forms and CRUD consistency |
| [Login](Login_Checklist.md) | Authentication, sessions and negative inputs |
| [Localization](Localization_Checklist.md) | Text, formats, timezones and directionality |
| [Smoke, sanity, regression](Regression_Sanity_Smoke.md) | Selecting checks for build acceptance and changed behavior |
| [Security](Security_Checklist.md) | Basic access-control, session and data-protection checks |
| [Performance](Performance_Checklist.md) | Baseline, workload and recovery observations |

Before execution, record application/build, environment, actor/role, browser/device, date and requirement references. Replace example limits with agreed criteria. Record actual results and evidence per failed or blocked item.

Statuses: **Not run** (unexecuted), **Passed** (expected result observed), **Failed** (mismatch), **Blocked** (cannot execute), **Not applicable** (excluded with rationale). Blocked and Not applicable are not interchangeable.
